◆ rayTriangleIntersect()

void rayTriangleIntersect ( const TriMesh & in_Mesh,
const int in_Triangle_idx,
const Ray & in_Ray,
RayHit & out_Result )

レイが指定された三角形と交差するかどうかを判定する。交差している場合、その交差点の情報（交差距離、位置、法線など）を出力変数 out_Result に格納する。

指定された三角形（in_Triangle_idx）とレイ（in_Ray）の交差を計算し、交差点情報をout_Resultに保存します。交差しない場合、out_Result.tは初期値のままになります。

引数
[in]in_Meshメッシュデータ（三角形の頂点とインデックスを含む）
[in]in_Triangle_idx交差計算を行う三角形のインデックス
[in]in_Rayレイの情報（始点oと方向d）
[out]out_Result交差点の情報（交差距離t、UV座標alphaとbeta、表面交差フラグisFront）
参照
RayHit
処理フローの概要図

処理の概要:

  • メッシュから三角形の頂点（v1, v2, v3）を取得。
  • 三角形の法線を計算し、レイが表面に当たるか（isFront）を判定。
  • レイと三角形の平面との交差点を計算（t）。
  • 交差点が三角形内にある場合、バリュートリック座標（alpha, beta）を用いて交差位置を確認。
  • 結果をout_Resultに保存。
