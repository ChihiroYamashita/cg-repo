鏡面反射（反射光）の寄与を計算する関数

入射点での鏡面反射光の寄与を計算します。 鏡面反射では、反射ベクトルを計算し、その方向に向かうレイを追跡することで寄与を得ます。

引数
[in]in_x交差点の位置（3D座標）
[in]in_n交差点での法線ベクトル
[in]in_w_eye視線方向ベクトル（カメラから交差点への方向）
[in]in_ray_hit交差情報（交差距離、メッシュ、プリミティブインデックスなど）
[in]in_Objectシーン内のオブジェクト（メッシュ、マテリアル情報を含む）
[in]in_Material交差点のマテリアル情報
[in]in_AreaLightsシーン内のエリアライトリスト
[in]depth現在のレイの追跡深度
戻り値
Eigen::Vector3d 鏡面反射光の寄与（RGB値）

処理の流れ

1. 反射ベクトルの計算

入射方向と法線ベクトルから反射ベクトルを計算します。

const double e_dot_n = in_w_eye.dot(in_n); // 入射方向と法線ベクトルの内積
Eigen::Vector3d w_L = 2.0 * in_n * e_dot_n - in_w_eye; // 反射ベクトル
w_L.normalize(); // ベクトルを正規化

数式で表すと次のようになります：

  • : 法線ベクトル
  • : 入射方向（視線方向）
  • : 反射ベクトル

2. 新しいレイの生成と追跡

計算した反射ベクトルを用いて新しいレイを生成し、そのレイを追跡します。

Ray ray;
ray.o = in_x; // レイの始点
ray.d = w_L; // レイの方向
ray.depth = depth + 1; // 深度をインクリメント
ray.prev_mesh_idx = in_ray_hit.mesh_idx; // 現在の交差情報を保持
ray.prev_primitive_idx = in_ray_hit.primitive_idx;
RayHit new_ray_hit;
rayTracing(in_Object, in_AreaLights, ray, new_ray_hit); // 新しいレイの追跡
