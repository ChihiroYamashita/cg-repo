屈折光の寄与を計算する関数

入射点での屈折光の寄与を計算します。 屈折光は、スネルの法則に基づき、異なる屈折率を持つ媒質間での光の屈折方向を計算します。 また、全反射が発生する場合には反射光の寄与を計算します。

引数
[in]in_x交差点の位置（3D座標）
[in]in_n交差点での法線ベクトル
[in]in_w_eye視線方向ベクトル（カメラから交差点への方向）
[in]in_ray_hit交差情報（交差距離、メッシュ、プリミティブインデックスなど）
[in]in_Objectシーン内のオブジェクト（メッシュ、マテリアル情報を含む）
[in]in_Material交差点のマテリアル情報
[in]in_AreaLightsシーン内のエリアライトリスト
[in]depth現在のレイの追跡深度
戻り値
Eigen::Vector3d 屈折光の寄与（RGB値）

処理の流れ

1. 入射方向と法線の内積を計算

入射方向ベクトルと法線ベクトルの内積を計算します。

const double e_dot_n = in_w_eye.dot(in_n);
  • e_dot_n:
    • 入射方向の法線方向へのスカラー成分。

2. 屈折率を設定

表面の内側から外側へ出る場合と、外側から内側へ入る場合で屈折率を切り替えます。

const double eta = in_ray_hit.isFront ? in_Material.eta : 1.0 / in_Material.eta;
  • eta:
    • 屈折率の比を表します。
    • 内側から外側の場合：1.0 / eta。
    • 外側から内側の場合：eta。

3. 判定：全反射が発生するか

スネルの法則に基づいて、全反射が発生するかどうかを判定します。

const double inside_sqrt = 1.0 - eta*eta * (1.0 - e_dot_n * e_dot_n);
if (inside_sqrt < 0.0)
{
return computeReflection(in_x, in_n, in_w_eye, in_ray_hit, in_Object, in_Material, in_AreaLights, depth);
}

  • inside_sqrt:
    • スネルの法則に基づく計算結果。
    • ( \text{inside_sqrt} < 0 ) の場合、全反射が発生。
  • 全反射の場合:
    • 屈折ベクトルを計算せず、反射ベクトルを計算してその寄与を返します。

4. 屈折ベクトルの計算

全反射が発生しない場合、スネルの法則を使って屈折ベクトルを計算します。

Eigen::Vector3d w_t = -in_n * sqrt(inside_sqrt) - eta * (in_w_eye - e_dot_n * in_n);
w_t.normalize();
  • 数式：

  • 第一項:
    • 法線方向の成分（曲がり具合を決定）。
  • 第二項:
    • 入射方向の成分を屈折率で調整。

5. 新しいレイを生成し追跡

計算した屈折ベクトルを使って新しいレイを生成し、交差点を追跡します。

Ray ray;
ray.o = in_x;
ray.d = w_t;
ray.depth = depth + 1;
ray.prev_mesh_idx = in_ray_hit.mesh_idx;
ray.prev_primitive_idx = in_ray_hit.primitive_idx;
RayHit new_ray_hit;
rayTracing(in_Object, in_AreaLights, ray, new_ray_hit);
