##  全体フロー：OpenGL描画の処理の流れ（Qt版）
```text
          QOpenGLWidgetによる初期化 & 描画
┌─────────────────────────────────────────┐
│                                        │
│           1回だけ呼ばれる関数         │
│   ┌──────────────┐                       │
│   │ initializeGL()│← OpenGLの初期設定    │
│   └──────────────┘                       │
│                                        │
│         毎フレーム or 明示的再描画で呼ばれる関数 │
│   ┌──────────────┐                       │
│   │ resizeGL()    │← リサイズ時に呼ばれる │

└─────────────────────────────────────────┘
```

##  普通、視野変換、投影変換、ビューポート変換の順に呼ばれませんか？
とても良い視点です。ご指摘の通り、**理論的・概念的には**：

> **視野変換（View） → 投影変換（Projection） → ビューポート変換（Viewport）**

の順で処理されるのが自然です。なぜなら、OpenGLのグラフィックスパイプラインは以下のような順番で頂点に対して変換をかけていくからです：

```
[モデル座標]
 → モデリング変換
 → 視野変換（カメラ座標系へ）
 → 投影変換（視錐台 → 正規化デバイス座標）
 → ビューポート変換（スクリーン座標へ）
```

---

## ✅ ではなぜ `paintGL()` では投影→ビューポート→視野 の順なのか？

これは **OpenGL の状態設定**と**描画タイミング**の関係によるものです。

### OpenGLの描画順序（実際の`paintGL()`）：

```cpp
updateProjectionMatrix(); // ① 投影行列の設定
glViewport(...);          // ② スクリーンサイズの設定
projection_and_modelview(); // ③ カメラの視点を設定
```

### なぜこの順でOKか：

* OpenGLでは、「**行列の設定**」は **描画が始まる前**に行っておけばよく、実際の行列計算は内部で最終的に以下のように合成されます：

  ```cpp
  gl_Position = ProjectionMatrix × ModelViewMatrix × vertex
  ```

* モデルビュー行列（視野変換）は `glMatrixMode(GL_MODELVIEW)` 時に設定。

* 投影行列は `glMatrixMode(GL_PROJECTION)` 時に設定。

* **それぞれの行列スタックは独立に管理される**ので、順番が逆でも最終的に行列積が正しく合成されればOKです。

---

## ✅ ビューポート変換はいつでもOK？

はい、`glViewport()` は \*\*座標変換ではなく「画面にどうマッピングするか」\*\*の設定です。したがって、描画前に呼ばれていれば OK です。行列に関係なく独立に働きます。

---

## 🔁 結論：理論 vs 実装順の違い

| 観点            | 理論的な順序 | OpenGL 実装での順序（あなたのコード）             |
| ------------- | ------ | ---------------------------------- |
| モデル変換 → 視野変換  | ✅      | ✅ (`glLoadIdentity` + `gluLookAt`) |
| 視野変換 → 投影変換   | ✅      | ❌（逆順でもOK、状態として管理）                  |
| 投影変換 → ビューポート | ✅      | ✅                                  |
| 行列が正しく積まれるか   | ✅      | ✅ 問題なし                             |

---

つまり、

> **理論的には視野→投影→ビューポートが自然ですが、OpenGLでは投影→ビューポート→視野でも動作に問題はありません。**

ただし、「理論通りに組むほうが可読性・教育的には望ましい」とされることが多いです。
