\begin{DoxyItemize}
\item Open\+GLでは、「\texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*}行列の設定\texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*}」は \texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*}描画が始まる前\texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*}に行っておけばよく、実際の行列計算は内部で最終的に以下のように合成されます：


\begin{DoxyCode}{0}

\end{DoxyCode}

\item モデルビュー行列（視野変換）は {\ttfamily gl\+Matrix\+Mode(\+GL\+\_\+\+MODELVIEW)} 時に設定。
\item 投影行列は {\ttfamily gl\+Matrix\+Mode(\+GL\+\_\+\+PROJECTION)} 時に設定。
\item \texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*}それぞれの行列スタックは独立に管理される\texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*}ので、順番が逆でも最終的に行列積が正しく合成されれば\+OKです。
\end{DoxyItemize}
