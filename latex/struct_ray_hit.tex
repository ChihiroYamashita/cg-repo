\doxysubsection{詳解}
レイと三角形の交差点情報を保持する構造体 

この構造体には、レイが交差した際の交差点の情報を保持します。交差距離、交差位置、法線、交差したオブジェクトの識別情報などを含みます。

復習 \doxylink{md__doxygen_2technical__terms_barycentric_coordinates}{バリュートリック座標} を参照してください。
\begin{DoxyItemize}
\item {\bfseries{t}}\+: 交差点までの距離。交差しない場合は非常に大きな値（例\+: 無限大）。
\item {\bfseries{alpha}}\+: 交差点におけるバリュートリック座標の第一成分（α）。交差点が三角形のどの位置にあるかを示すために使用されます。 通常、三角形の3つの頂点（v1, v2, v3）に対して、交差点 {\ttfamily x} は {\ttfamily x = alpha \texorpdfstring{$\ast$}{*} v1 + beta \texorpdfstring{$\ast$}{*} v2 + gamma \texorpdfstring{$\ast$}{*} v3} と表現され、 {\ttfamily alpha + beta + gamma = 1} の関係があります。
\item {\bfseries{beta}}\+: バリュートリック座標 (β)。交差点におけるバリュートリック座標の第二成分（β）。{\ttfamily alpha} と同様に、三角形内の位置を特定するために使用されます。

復習 \doxylink{md__doxygen_2technical__terms_about_index}{インデックス} を参照してください。
\item {\bfseries{mesh\+\_\+idx}}\+: 交差したメッシュのインデックス。
\item {\ttfamily \texorpdfstring{$<$}{<} -\/1}\+: レイがどのオブジェクトとも交差していないことを示します。
\item {\ttfamily -\/1}\+: レイがエリアライトと交差したことを示します。
\item {\ttfamily \texorpdfstring{$>$}{>}= 0}\+: レイがシーン内の特定のオブジェクトメッシュと交差したことを示し、そのメッシュの配列インデックスが格納されます。
\item 復習 \doxylink{md__doxygen_2technical__terms_about_primitive}{プリミティブ} を参照してください。~\newline

\item {\bfseries{primitive\+\_\+idx}}\+: 交差したプリミティブ（三角形またはライト）のインデックス。 交差したプリミティブ（個々の三角形またはエリアライト）のインデックス。
\item {\ttfamily \texorpdfstring{$<$}{<} 0}\+: レイがどのプリミティブとも交差していないことを示します。
\item {\ttfamily mesh\+\_\+idx = -\/1} の場合：交差したエリアライトの配列インデックスが格納されます。
\item {\ttfamily mesh\+\_\+idx \texorpdfstring{$>$}{>}= 0} の場合：交差したメッシュ内の三角形の配列インデックスが格納されます。
\item {\bfseries{is\+Front}}\+: レイが三角形の表面（正面）に当たったかどうか。
\begin{DoxyItemize}
\item {\ttfamily true}\+: 表面に交差。
\item {\ttfamily false}\+: 裏面に交差。 
\end{DoxyItemize}
\end{DoxyItemize}
