3Dオブジェクトを構成する基本的な要素として、三角形メッシュの情報を格納します。 各メンバー変数の詳細を以下に示します：\hypertarget{struct_tri_mesh_autotoc_md9}{}\doxysubsubsubsection{\texorpdfstring{メンバー変数}{メンバー変数}}\label{struct_tri_mesh_autotoc_md9}

\begin{DoxyItemize}
\item {\bfseries{vertices}}\+:
\begin{DoxyItemize}
\item メッシュの頂点座標リスト。
\item 各頂点は3次元ベクトルで表されます。
\end{DoxyItemize}
\item {\bfseries{vertex\+\_\+normals}}\+:
\begin{DoxyItemize}
\item 頂点の法線ベクトルリスト。
\item シェーディング計算に使用されます。
\end{DoxyItemize}
\item {\bfseries{tex\+\_\+coords}}\+:
\begin{DoxyItemize}
\item テクスチャ座標リスト。
\item 各頂点に対応するテクスチャマッピングの\+UV座標。
\end{DoxyItemize}
\item {\bfseries{triangles}}\+:
\begin{DoxyItemize}
\item 三角形を構成する\texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*}頂点インデックス\texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*}のリスト。
\item 各三角形は3つの頂点インデックスで定義されます。
\end{DoxyItemize}
\item {\bfseries{vertex\+\_\+colors}}\+:
\begin{DoxyItemize}
\item 頂点カラーリスト（オプション）。
\item 頂点ごとのカラー情報。
\end{DoxyItemize}
\item {\bfseries{material}}\+:
\begin{DoxyItemize}
\item 材質情報を格納する構造体。
\item 拡散反射係数 ({\ttfamily kd})、鏡面反射係数 ({\ttfamily ks})、屈折係数 ({\ttfamily kt})、屈折率 ({\ttfamily eta})、およびテクスチャ。
\end{DoxyItemize}
