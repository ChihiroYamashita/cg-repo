\subsubsection*{template$<$typename \mbox{\hyperlink{benchmark-blocking-sizes_8cpp_af5fcaa2ea9f565466ca96c2992ea0771_af5fcaa2ea9f565466ca96c2992ea0771}{Matrix\+Type}}$>$\newline
class Eigen\+::\+Matrix\+Power\+Atomic$<$ Matrix\+Type $>$}
Class for computing matrix powers. 


\begin{DoxyTemplParams}{テンプレート引数}
{\em Matrix\+Type} & type of the base, expected to be an instantiation of the \doxylink{class_eigen_1_1_matrix}{Matrix} class template.\\
\hline
\end{DoxyTemplParams}
This class is capable of computing triangular real/complex matrices raised to a power in the interval $ (-1, 1) $.

\begin{DoxyNote}{覚え書き}
Currently this class is only used by \doxylink{class_eigen_1_1_matrix_power}{Matrix\+Power}. One may insist that this be nested into \doxylink{class_eigen_1_1_matrix_power}{Matrix\+Power}. This class is here to facilitate future development of triangular matrix functions. 
\end{DoxyNote}
