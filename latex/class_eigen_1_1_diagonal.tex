class Eigen\+::\+Diagonal$<$ Matrix\+Type, Index $>$}
Expression of a diagonal/subdiagonal/superdiagonal in a matrix 


\begin{DoxyParams}{引数}
{\em Matrix\+Type} & the type of the object in which we are taking a sub/main/super diagonal \\
\hline
{\em Diag\+Index} & the index of the sub/super diagonal. The default is 0 and it means the main diagonal. A positive value means a superdiagonal, a negative value means a subdiagonal. You can also use Dynamic\+Index so the index can be set at runtime.\\
\hline
\end{DoxyParams}
The matrix is not required to be square.

This class represents an expression of the main diagonal, or any sub/super diagonal of a square matrix. It is the return type of \doxylink{class_eigen_1_1_matrix_base_aecfec14fd51817fd3e8b61219e81a01e_aecfec14fd51817fd3e8b61219e81a01e}{Matrix\+Base\+::diagonal()} and \doxylink{class_eigen_1_1_matrix_base_a74bbbfeceaf3f9204643f61c2ed271d5_a74bbbfeceaf3f9204643f61c2ed271d5}{Matrix\+Base\+::diagonal(\+Index)} and most of the time this is the only way it is used.
