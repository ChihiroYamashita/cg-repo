This function computes the inverse-\/matrix matrix product inverse({\ttfamily \texorpdfstring{$\ast$}{*}this}) \texorpdfstring{$\ast$}{*} {\itshape other} if {\itshape Side==On\+The\+Left} (the default), or the right-\/inverse-\/multiply {\itshape other} \texorpdfstring{$\ast$}{*} inverse({\ttfamily \texorpdfstring{$\ast$}{*}this}) if {\itshape Side==On\+The\+Right}.

Note that the template parameter {\ttfamily Side} can be omitted, in which case {\ttfamily Side==On\+The\+Left} 

The matrix {\ttfamily \texorpdfstring{$\ast$}{*}this} must be triangular and invertible (i.\+e., all the coefficients of the diagonal must be non zero). It works as a forward (resp. backward) substitution if {\ttfamily \texorpdfstring{$\ast$}{*}this} is an upper (resp. lower) triangular matrix.
