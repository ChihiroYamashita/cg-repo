\subsubsection*{template$<$typename Plain\+Object\+Type, \mbox{\hyperlink{level1__cplx__impl_8h_a4e8e1c1bb9d4e05fc671fc133ec9dc9b_a4e8e1c1bb9d4e05fc671fc133ec9dc9b}{int}} Options\+\_\+, template$<$ class $>$ class Make\+Pointer\+\_\+$>$\newline
class Eigen\+::\+Tensor\+Map$<$ Plain\+Object\+Type, Options\+\_\+, Make\+Pointer\+\_\+ $>$}
A tensor expression mapping an existing array of data. 

{\ttfamily template \texorpdfstring{$<$}{<}class\texorpdfstring{$>$}{>} class Make\+Pointer\+\_\+} is added to convert the host pointer to the device pointer. It is added due to the fact that for our device compiler {\ttfamily T\texorpdfstring{$\ast$}{*}} is not allowed. If we wanted to use the same Evaluator functions we have to convert that type to our pointer {\ttfamily T}. This is done through our {\ttfamily Make\+Pointer\+\_\+} class. By default the Type in the {\ttfamily Make\+Pointer\+\_\+\texorpdfstring{$<$}{<}T\texorpdfstring{$>$}{>}} is {\ttfamily T\texorpdfstring{$\ast$}{*}} . Therefore, by adding the default value, we managed to convert the type and it does not break any existing code as its default value is {\ttfamily T\texorpdfstring{$\ast$}{*}}.
