Householder rank-\/revealing QR decomposition of a matrix with column-\/pivoting 


\begin{DoxyTemplParams}{テンプレート引数}

\hline
\end{DoxyTemplParams}
This class performs a rank-\/revealing QR decomposition of a matrix {\bfseries{A}} into matrices {\bfseries{P}}, {\bfseries{Q}} and {\bfseries{R}} such that   \[
 \mathbf{A} \, \mathbf{P} = \mathbf{Q} \, \mathbf{R}
\] by using Householder transformations. Here, {\bfseries{P}} is a permutation matrix, {\bfseries{Q}} a unitary matrix and {\bfseries{R}} an upper triangular matrix.

This decomposition performs column pivoting in order to be rank-\/revealing and improve numerical stability. It is slower than \doxylink{class_eigen_1_1_householder_q_r}{Householder\+QR}, and faster than \doxylink{class_eigen_1_1_full_piv_householder_q_r}{Full\+Piv\+Householder\+QR}.

This class supports the \doxylink{group___inplace_decomposition}{inplace decomposition } mechanism.
