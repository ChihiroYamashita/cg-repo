\subsubsection*{template$<$typename Derived$>$\newline
class Eigen\+::\+Simplicial\+Cholesky\+Base$<$ Derived $>$}
A base class for direct sparse Cholesky factorizations 

This is a base class for LL\texorpdfstring{$^\wedge$}{\string^}T and LDL\texorpdfstring{$^\wedge$}{\string^}T Cholesky factorizations of sparse matrices that are selfadjoint and positive definite. These factorizations allow for solving A.\+X = B where X and B can be either dense or sparse.

In order to reduce the fill-\/in, a symmetric permutation P is applied prior to the factorization such that the factorized matrix is P A P\texorpdfstring{$^\wedge$}{\string^}-\/1.
