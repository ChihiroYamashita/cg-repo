\doxysubsection{詳解}
アプリケーションのメインウィンドウクラス 

-\/-\/-\/-\/-\/---QT\+\_\+\+BEGIN\+\_\+\+NAMESPACE と QT\+\_\+\+END\+\_\+\+NAMESPACE マクロを使用して、\+Qt の名前空間の中に Ui\+::\+Main\+Window クラスを定義-\/-\/-\/-\/-\/--- 

Main\+Windowクラスは、アプリケーションのメインウィンドウを管理します。 カメラのキーフレーム操作やタイムラインの更新、\+GUIイベントの処理をサポートします。
