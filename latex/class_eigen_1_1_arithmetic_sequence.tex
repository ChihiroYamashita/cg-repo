\doxysubsection{詳解}
\subsubsection*{template$<$typename First\+Type, typename Size\+Type, typename Incr\+Type$>$\newline
class Eigen\+::\+Arithmetic\+Sequence$<$ First\+Type, Size\+Type, Incr\+Type $>$}
This class represents an arithmetic progression $ a_0, a_1, a_2, ..., a_{n-1}$ defined by its {\itshape first} value $ a_0 $, its {\itshape size} (aka length) {\itshape n}, and the {\itshape increment} (aka stride) that is equal to $ a_{i+1}-a_{i}$ for any {\itshape i}.

It is internally used as the return type of the \doxylink{namespace_eigen_a6db24b502633d158c17cb0677e7be4cb_a6db24b502633d158c17cb0677e7be4cb}{Eigen\+::seq} and \doxylink{namespace_eigen_a3a3c346d2a61d1e8e86e6fb4cf57fbda_a3a3c346d2a61d1e8e86e6fb4cf57fbda}{Eigen\+::seqN} functions, and as the input arguments of \doxylink{class_eigen_1_1_dense_base_a4ab85c7f3859f871bda589ee9cba93f2_a4ab85c7f3859f871bda589ee9cba93f2}{Dense\+Base\+::operator()(const Row\+Indices\&, const Col\+Indices\&)}, and most of the time this is the only way it is used.


\begin{DoxyTemplParams}{テンプレート引数}
{\em First\+Type} & type of the first element, usually an Index, but internally it can be a symbolic expression \\
\hline
{\em Size\+Type} & type representing the size of the sequence, usually an Index or a compile time integral constant. Internally, it can also be a symbolic expression \\
\hline
{\em Incr\+Type} & type of the increment, can be a runtime Index, or a compile time integral constant (default is compile-\/time 1)\\
\hline
\end{DoxyTemplParams}
