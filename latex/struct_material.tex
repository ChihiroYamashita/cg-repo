\doxysubsection{詳解}
オブジェクトの材質を表す構造体 

この構造体は、3\+Dオブジェクトの材質（マテリアル）情報を格納します。 材質はオブジェクトの表面の光反射特性や屈折特性、テクスチャ情報などを定義します。\hypertarget{struct_material_autotoc_md8}{}\doxysubsubsubsection{\texorpdfstring{メンバー変数\+:}{メンバー変数\+:}}\label{struct_material_autotoc_md8}

\begin{DoxyItemize}
\item {\bfseries{texture}}\+:
\begin{DoxyItemize}
\item オブジェクト表面に適用されるテクスチャ（画像）データ。
\item {\ttfamily GLuint} 型でテクスチャ\+IDを管理。
\item Open\+GLでロードされたテクスチャを識別するために使用されます。
\end{DoxyItemize}
\item {\bfseries{kd}} (拡散反射係数)\+:
\begin{DoxyItemize}
\item 材質の拡散反射成分を表すベクトル。
\item 例\+: マットな材質では光が表面全体に均等に散乱する。
\item 3次元ベクトル (R, G, B) で色を定義。
\end{DoxyItemize}
\item {\bfseries{ks}} (鏡面反射係数)\+:
\begin{DoxyItemize}
\item 材質の鏡面反射成分を表すベクトル。
\item 光源からの光が特定の方向に強く反射する性質を制御。
\item 3次元ベクトル (R, G, B) で色を定義。
\end{DoxyItemize}
\item {\bfseries{kt}} (透過率)\+:
\begin{DoxyItemize}
\item 材質の透過特性を表すベクトル。
\item 透明なオブジェクト（例\+: ガラスや水）の光透過性を示す。
\item 3次元ベクトル (R, G, B) で色を定義。
\end{DoxyItemize}
\item {\bfseries{eta}} (屈折率)\+:
\begin{DoxyItemize}
\item 材質の屈折率を表すスカラ値。
\item 光が異なる媒質に入る際の屈折の度合いを示す。
\item 例\+: 空気の屈折率は約1.0、ガラスは約1.5。
\end{DoxyItemize}
\end{DoxyItemize}\hypertarget{struct_material_autotoc_md9}{}\doxysubsubsubsection{\texorpdfstring{主な用途\+:}{主な用途\+:}}\label{struct_material_autotoc_md9}
