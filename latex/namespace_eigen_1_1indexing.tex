\doxysubsection{詳解}
The sole purpose of this namespace is to be able to import all functions and symbols that are expected to be used within operator() for indexing and slicing. If you already imported the whole \doxylink{namespace_eigen}{Eigen} namespace\+: 
\begin{DoxyCode}{0}
\DoxyCodeLine{\textcolor{keyword}{using\ namespace\ }\mbox{\hyperlink{namespace_eigen}{Eigen}};\ }

\end{DoxyCode}
 then you are already all set. Otherwise, if you don\textquotesingle{}t want/cannot import the whole \doxylink{namespace_eigen}{Eigen} namespace, the following line\+: 
\begin{DoxyCode}{0}
\DoxyCodeLine{\textcolor{keyword}{using\ namespace\ }\mbox{\hyperlink{namespace_eigen_1_1indexing}{Eigen::indexing}};\ }

\end{DoxyCode}
 is equivalent to\+: 
\begin{DoxyCode}{0}
\DoxyCodeLine{\textcolor{keyword}{using\ }Eigen::all;}
\DoxyCodeLine{\textcolor{keyword}{using\ }\mbox{\hyperlink{namespace_eigen_a6db24b502633d158c17cb0677e7be4cb_a6db24b502633d158c17cb0677e7be4cb}{Eigen::seq}};}
