\subsubsection*{template$<$typename \+\_\+\+Matrix\+Type$>$\newline
class Eigen\+::\+SPQR$<$ \+\_\+\+Matrix\+Type $>$}
\doxylink{struct_eigen_1_1_sparse}{Sparse} QR factorization based on Suite\+Sparse\+QR library 

This class is used to perform a multithreaded and multifrontal rank-\/revealing QR decomposition of sparse matrices. The result is then used to solve linear leasts\+\_\+square systems. Clearly, a QR factorization is returned such that A\texorpdfstring{$\ast$}{*}P = Q\texorpdfstring{$\ast$}{*}R where \+:

P is the column permutation. Use \doxylink{class_eigen_1_1_s_p_q_r_ab1b7f54ba1cd8d77506ae676fea4fec0_ab1b7f54ba1cd8d77506ae676fea4fec0}{cols\+Permutation()} to get it.

Q is the orthogonal matrix represented as Householder reflectors. Use \doxylink{class_eigen_1_1_s_p_q_r_ab1e43f45b2b92623725b572793873f13_ab1e43f45b2b92623725b572793873f13}{matrix\+Q()} to get an expression and \doxylink{class_eigen_1_1_s_p_q_r_ab1e43f45b2b92623725b572793873f13_ab1e43f45b2b92623725b572793873f13}{matrix\+Q()}.transpose() to get the transpose. You can then apply it to a vector.
