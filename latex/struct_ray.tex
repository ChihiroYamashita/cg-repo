\doxysubsection{詳解}
レイ（\+Ray）を表す構造体 

レイは、光線追跡や可視化においてシーン内を進む光の経路を表します。この構造体は、レイの始点（origin）、方向（direction）、追跡の深さ、直前に交差したオブジェクトの情報を格納します。


\begin{DoxyItemize}
\item {\bfseries{o}}\+: レイの始点。通常はカメラの視点や反射点の位置。
\item {\bfseries{d}}\+: レイの方向。単位ベクトルとして正規化されていることが望ましい。
\item {\bfseries{depth}}\+: このレイが何回目の反射・屈折によるものかを示す深さカウント（再帰回数）。
\item {\bfseries{prev\+\_\+mesh\+\_\+idx}}\+: 直前に交差したメッシュのインデックス。交差の再利用を避けるために用いる。
\item {\bfseries{prev\+\_\+primitive\+\_\+idx}}\+: 直前に交差したプリミティブ（三角形）のインデックス。これも再交差を防ぐ目的で使用。
\end{DoxyItemize}

\begin{DoxyNote}{覚え書き}
{\ttfamily depth}、{\ttfamily prev\+\_\+mesh\+\_\+idx}、{\ttfamily prev\+\_\+primitive\+\_\+idx} は再帰的な光線追跡において重要で、自己交差を防止するために利用されます。
\end{DoxyNote}
