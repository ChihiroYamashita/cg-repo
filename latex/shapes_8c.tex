\doxysubsection{詳解}
This program is a test harness for the various shapes in Open\+GLUT. 

It may also be useful to see which parameters control what behavior in the Open\+GLUT objects.

Spinning wireframe and solid-\/shaded shapes are displayed. Some parameters can be adjusted.

Keys\+:
\begin{DoxyItemize}
\item {\ttfamily Esc ~} Quit
\item {\ttfamily q Q ~} Quit
\item {\ttfamily i I ~} Show info
\item {\ttfamily p P ~} Toggle perspective or orthographic projection
\item {\ttfamily r R ~} Toggle fixed or animated rotation around model X-\/axis
\item {\ttfamily = + ~} Increase {\itshape slices} 
\item {\ttfamily -\/ \+\_\+ ~} Decreate {\itshape slices} 
\item {\ttfamily , \texorpdfstring{$<$}{<} ~} Decreate {\itshape stacks} 
\item {\ttfamily . \texorpdfstring{$>$}{>} ~} Increase {\itshape stacks} 
\item {\ttfamily 9 ( ~} Decreate {\itshape depth} (Sierpinski Sponge)
\item {\ttfamily 0 ) ~} Increase {\itshape depth} (Sierpinski Sponge)
\item {\ttfamily up~ ~} Increase "{}outer radius"{}
\item {\ttfamily down~} Decrease "{}outer radius"{}
\item {\ttfamily left~} Decrease "{}inner radius"{}
\item {\ttfamily right} Increase "{}inner radius"{}
\item {\ttfamily Pg\+Up~} Next shape-\/drawing function
\item {\ttfamily Pg\+Dn~} Prev shape-\/drawing function
\end{DoxyItemize}
