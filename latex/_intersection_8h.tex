{\bfseries{処理の概要}}\+:
\begin{DoxyItemize}
\item エリアライトの中心座標 {\ttfamily pos} と辺ベクトル {\ttfamily arm\+\_\+u}、{\ttfamily arm\+\_\+v} を取得。
\item 法線ベクトル {\ttfamily light\+\_\+normal} を計算し、レイが裏面か表面に当たるかを判定（{\ttfamily is\+Front}）。
\item レイとライトの平面との交差点を計算し、交差距離 {\ttfamily t} を取得。
\item 交差点の位置をライトのローカル\+UV座標に変換し、範囲 (\mbox{[}-\/1, 1\mbox{]}) 内にあるかを確認。
\item 交差が有効であれば、交差点情報（{\ttfamily t}、{\ttfamily alpha}、{\ttfamily beta}、{\ttfamily is\+Front}）を {\ttfamily out\+\_\+\+Result} に保存。
\end{DoxyItemize}

{\bfseries{処理の概要}}\+:
\begin{DoxyItemize}
\item メッシュから三角形の頂点（{\ttfamily v1}, {\ttfamily v2}, {\ttfamily v3}）を取得。
\item 三角形の法線を計算し、レイが表面に当たるか（{\ttfamily is\+Front}）を判定。
\item レイと三角形の平面との交差点を計算（{\ttfamily t}）。
\item 交差点が三角形内にある場合、バリュートリック座標（{\ttfamily alpha}, {\ttfamily beta}）を用いて交差位置を確認。
\item 結果を{\ttfamily out\+\_\+\+Result}に保存。 
\end{DoxyItemize}
