\doxysubsection{詳解}
シーン内のオブジェクトを表す構造体 

この構造体は、複数の三角形メッシュ ({\ttfamily \doxylink{struct_tri_mesh}{Tri\+Mesh}}) を持つ3\+Dオブジェクトを表します。 シーン内の物体（例\+: 箱、球、人型モデルなど）を1つのまとまりとして扱うために使用されます。

\begin{DoxyItemize}
\item {\bfseries{meshes}}\+:
\begin{DoxyItemize}
\item このオブジェクトを構成する三角形メッシュ ({\ttfamily \doxylink{struct_tri_mesh}{Tri\+Mesh}}) のリスト。
\item 各メッシュ ({\ttfamily \doxylink{struct_tri_mesh}{Tri\+Mesh}}) は以下の情報を持ちます：
\begin{DoxyItemize}
\item 頂点座標 ({\ttfamily vertices})
\begin{DoxyItemize}
\item メッシュを構成する3\+D空間内の座標リスト。
\end{DoxyItemize}
\item 頂点法線 ({\ttfamily vertex\+\_\+normals})
\begin{DoxyItemize}
\item 各頂点の表面の方向を表すベクトル。
\end{DoxyItemize}
\item テクスチャ座標 ({\ttfamily tex\+\_\+coords})
\begin{DoxyItemize}
\item テクスチャマッピングのための\+UV座標。
\end{DoxyItemize}
\item 三角形インデックス ({\ttfamily triangles})
\begin{DoxyItemize}
\item メッシュを構成する三角形の頂点インデックス。
\end{DoxyItemize}
\item 頂点カラー ({\ttfamily vertex\+\_\+colors})
\begin{DoxyItemize}
\item 頂点ごとの色情報（オプション）。
\end{DoxyItemize}
\item 材質情報 ({\ttfamily material})
\begin{DoxyItemize}
\item 光の反射特性やテクスチャ情報を格納する構造体。
\end{DoxyItemize}
\end{DoxyItemize}
