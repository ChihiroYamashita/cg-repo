This class represents an expression of either a fixed-\/size or dynamic-\/size reshape. It is the return type of \doxylink{class_eigen_1_1_dense_base_a154c89b42c44e2b07923cf3ba45031aa_a154c89b42c44e2b07923cf3ba45031aa}{Dense\+Base\+::reshaped(\+NRows\+Type,\+NCols\+Type)} and most of the time this is the only way it is used.

However, in C++98, if you want to directly maniputate reshaped expressions, for instance if you want to write a function returning such an expression, you will need to use this class. In C++11, it is advised to use the {\itshape auto} keyword for such use cases.
