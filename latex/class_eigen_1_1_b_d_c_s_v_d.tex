\subsubsection*{template$<$typename \+\_\+\+Matrix\+Type$>$\newline
class Eigen\+::\+BDCSVD$<$ \+\_\+\+Matrix\+Type $>$}
class Bidiagonal Divide and Conquer SVD 


\begin{DoxyTemplParams}{テンプレート引数}
{\em \+\_\+\+Matrix\+Type} & the type of the matrix of which we are computing the SVD decomposition\\
\hline
\end{DoxyTemplParams}
This class first reduces the input matrix to bi-\/diagonal form using class Upper\+Bidiagonalization, and then performs a divide-\/and-\/conquer diagonalization. Small blocks are diagonalized using class \doxylink{class_eigen_1_1_jacobi_s_v_d}{Jacobi\+SVD}. You can control the switching size with the \doxylink{class_eigen_1_1_b_d_c_s_v_d_aa21c0cc5e99c861970bae45d94cae9ad_aa21c0cc5e99c861970bae45d94cae9ad}{set\+Switch\+Size()} method, default is 16. For small matrice (\texorpdfstring{$<$}{<}16), it is thus preferable to directly use \doxylink{class_eigen_1_1_jacobi_s_v_d}{Jacobi\+SVD}. For larger ones, \doxylink{class_eigen_1_1_b_d_c_s_v_d}{BDCSVD} is highly recommended and can several order of magnitude faster.

\begin{DoxyWarning}{警告}
this algorithm is unlikely to provide accurate result when compiled with unsafe math optimizations. For instance, this concerns Intel\textquotesingle{}s compiler (ICC), which performs such optimization by default unless you compile with the {\ttfamily -\/fp-\/model} {\ttfamily precise} option. Likewise, the {\ttfamily -\/ffast-\/math} option of GCC or clang will significantly degrade the accuracy.
\end{DoxyWarning}
