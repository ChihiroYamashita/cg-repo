# Pass_tracing

## 概要

| 記号                               | 意味             |
| -------------------------------- | -------------- |
| $$C_i$$                            | 出力される色（輝度）     |
| $a_g$                            | グローバル環境光       |
| $a_l$                            | 光源の環境光         |
| $a_m$                            | 材質の環境反射率       |
| $d_l$                            | 光源の拡散光強度       |
| $d_m$                            | 材質の拡散反射率       |
| $\vec{L}$                        | 光の方向ベクトル       |
| $\vec{n}$                        | 法線ベクトル         |
| $\vec{L} \cdot \vec{n}$          | 光と法線の角度（cosθ）  |
| $\max(\vec{L} \cdot \vec{n}, 0)$ | 負の内積を0で切る（影対策） |
